# Cam Parker

I build tools for AI agents, mostly skills that let you check an agent's work before anyone relies on it.

Current public work:

- [skills](https://github.com/camparkr/skills): agent skills for Claude Code, Codex and Gemini CLI,
  starting with *dry-run*, which tests a planned change before the change is merged, published or put to
  use.

Each skill is MIT-licensed and installs with one script.
